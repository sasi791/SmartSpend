# SmartSpend – Personal Expense Analysis & Spending Prediction

## Project Overview
SmartSpend is a Python-based Data Science project that analyzes personal expenses and uses Machine Learning models to predict monthly spending.

## Objectives
- Analyze total and average expenses.
- Identify category-wise spending.
- Visualize monthly spending trends.
- Compare Linear Regression and Random Forest models.
- Predict future monthly spending.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn

## Dataset
The project currently uses synthetically generated sample expense data. It includes date, category, amount, and payment mode.

## How to Run
1. Install Python.
2. Install dependencies using `pip install -r requirements.txt`.
3. Run `python main.py`.

## Outputs
The project generates cleaned expense data, category-wise and monthly spending summaries, visualizations, and Machine Learning evaluation results.

## Machine Learning
Linear Regression and Random Forest are compared using MAE, RMSE, and R² score. The current model scores should be interpreted carefully because the sample dataset is synthetic and prediction performance needs further improvement.

## Project Status
The basic project pipeline runs successfully. The data analysis, visualizations, and model evaluation outputs are generated.
